# 📊 FinTrack – Personal Finance & Budget Tracker

**FinTrack** is a full-stack web application that helps users track their income and expenses, analyze spending habits, and manage personal finances through a clean and interactive dashboard.

---

## 🚀 Features

### 👤 User Features
- 🔐 User Authentication (Sign Up & Sign In)
- 📊 Personalized Dashboard
- 💰 Add and manage income
- 💸 Add and manage expenses
- 🧾 View recent transactions
- 📈 Visual financial overview using charts
- 🔓 Secure logout

---

## 📊 Dashboard Highlights
- Total Balance calculation
- Total Income & Total Expense summary
- Recent transaction history
- Income vs Expense pie chart
- Last 30 days income & expense analysis
